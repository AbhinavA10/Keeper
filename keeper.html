Every file in each group (e.g. NEF + JPG, HEIC + Live Photo MOV) and any NX Studio sidecars will be moved to the Recycle Bin.

Fix dates

Sets each JPEG's Date Modified to its Date Taken (from the photo's EXIF, or its NEF if the JPEG has none). Only the file's timestamp changes; the photo itself isn't touched.

Keyboard shortcuts

OOpen another folder (Keeper reopens the last one next time) BShow / hide the folder sidebar: nearby and recent folders, with how many photos each still has to sort GSwitch between grid and single-photo view EnterGrid: open the selected photo (or click it again; the first click selects it) EscSingle view: back to the grid TSingle view: show / hide the filmstrip of thumbnails ← →Previous / next (also Space, Backspace); ↑ ↓ move by rows in the grid. Single view skips rejected photos; open one from the grid to see it. XToggle reject 1 – 5Set star rating 0Clear rating SToggle social media — shareable, no people (red label in NX Studio; R also works) FToggle flagged — needs more correction in NX Studio (blue label). A photo has one label, so this replaces social media. ZZoom to 100% (or click the photo) PPlay / pause video Ctrl ZUndo last change Shift FCycle filter AToggle auto-advance Home EndFirst / last DelReview and delete rejected items
